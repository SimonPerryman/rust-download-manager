# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[Report a vulnerability](https://github.com/SimonPerryman/rust-download-manager/security/advisories/new)
form, not in a public issue or pull request. The report stays private
between you and the maintainer until a fix is ready.

A useful report includes:

- what the problem is and what an attacker could do with it;
- the steps to reproduce it, such as a command, a URL or a small server
  that triggers it;
- the commit or version you tested, and your operating system;
- any fix or workaround you have in mind.

## Supported versions

Only the newest release gets security fixes; there are no fix releases
for older versions, so update to the newest one.

## What to expect

rdm has a single maintainer, so responses are best effort and there is no
fixed timescale. The aim is to acknowledge each report, keep you updated
while it is looked at, and credit you in the advisory unless you would
rather not be named.
